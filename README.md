# 📚 SQL Bookstore Data Analysis

A SQL-based data analysis project exploring a bookstore dataset containing **Books, Customers, and Orders** tables.
The goal of this project is to practice and demonstrate **SQL querying, relational database concepts, and business-oriented data analysis**.

---

# 🗂 Dataset Overview

The project works with three relational tables:

### 📖 Books

Contains information about books available in the store.

Columns include:

* `Book_ID`
* `Title`
* `Author`
* `Genre`
* `Published_Year`
* `Price`
* `Stock`

---

### 👤 Customers

Stores details about customers.

Columns include:

* `Customer_ID`
* `Name`
* `City`
* `Country`

---

### 🛒 Orders

Stores information about book purchases.

Columns include:

* `Order_ID`
* `Customer_ID`
* `Book_ID`
* `Order_Date`
* `Quantity`
* `Total_Amount`

---

# 🧠 SQL Concepts Used

This project demonstrates practical usage of the following SQL concepts:

* SELECT queries
* Filtering using `WHERE`
* Sorting with `ORDER BY`
* Aggregation functions (`SUM`, `COUNT`, `AVG`, `MAX`)
* `GROUP BY`
* `HAVING`
* `INNER JOIN`
* `LEFT JOIN`
* Subqueries
* Data analysis queries

---

# 📊 Business Questions Answered

Some of the analysis queries in this project include:

### 📈 Sales Analysis

* Calculate total revenue generated from all orders
* Find the book that generated the highest revenue
* Find total revenue generated by each book
* Find revenue generated from each genre

---

### 📚 Book Insights

* Find the most expensive book
* Find the book with the lowest stock
* Find the most expensive book in each genre
* List books that have never been ordered

---

### 👥 Customer Analysis

* Find customers who placed the highest number of orders
* Identify customers who have placed at least two orders
* List customers who have never placed any order
* Identify cities where customers spent more than $30

---

### 📦 Inventory Insights

* Calculate remaining stock after fulfilling all orders
* Find total quantity of books sold per author
* Find total books sold for each genre
